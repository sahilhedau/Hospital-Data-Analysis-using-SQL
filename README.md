# 🏥 Hospital Management SQL Data Analysis Project

This is a complete, real-world **SQL Data Analyst portfolio project** based on a hospital dataset.  
The project simulates how data analysts work in healthcare domains by analyzing patient records, hospital operations, and treatment data using SQL.

This project demonstrates end-to-end SQL skills — from raw data understanding to business-oriented insights.

---

## 📌 Project Overview

The objective of this project is to use SQL to:

✅ Design and query hospital databases  
✅ Perform **Exploratory Data Analysis (EDA)**  
✅ Analyse Disease Trends                                                                     
✅ Answer **business and operational questions** using SQL  
✅ Extract actionable insights related to patients, doctors, admissions, and costs  

---

## 📁 Dataset Overview

The dataset represents hospital operations and patient records similar to what is used in real healthcare systems.

Each row corresponds to a hospital record such as a patient admission, treatment, or consultation.

🧾 **Key Columns (Dataset Summary):**
- **Patient_ID** – Unique patient identifier  
- **Patient_Name** – Name of the patient  
- **Age** – Patient age  
- **Gender** – Male / Female  
- **Disease / Diagnosis** – Medical condition  
- **Doctor_Name** – Assigned doctor  
- **Department** – Hospital department  
- **Admission_Date** – Date of admission  
- **Discharge_Date** – Date of discharge  
- **Treatment_Cost** – Cost of treatment  
- **Hospital_Stay_Days** – Length of stay  

*(Column names may vary slightly depending on dataset structure)*
